# Resume Analyzer

Resume Analyzer helps users evaluate and improve their resumes by extracting key information, scoring relevance to job descriptions, and providing actionable feedback.

Features
- Upload PDF resumes and analyze layout and content
- Extract sections (education, experience, skills)
- Score resumes and show visual summaries
- Simple web UI built with React + Vite

Getting started

Prerequisites
- Node.js 14+ and npm or Yarn
- Git (configured with your SSH key)

Install
```bash
npm install
# or
yarn
```

Run (development)
```bash
npm run dev
# or
yarn dev
```

Build
```bash
npm run build
# or
yarn build
```

Docker (optional)
- Build: `docker build -t resume-analyzer .`
- Run: `docker run -p 5173:5173 resume-analyzer`
